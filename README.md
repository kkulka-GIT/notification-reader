# Czytnik powiadomień / Notification Reader

Android Kotlin application that listens for notifications and announces short messages using Android TextToSpeech.

## Status

Working MVP. Notification access and TextToSpeech are working.

## Current Limitation

The app announces too many notifications.

## Next Planned Step

Add configurable filtering by application and notification type.

## Local Build Environment

- Debian aarch64 in Termux/proot
- Gradle 8.10.2
- compileSdk 34
- targetSdk 34
